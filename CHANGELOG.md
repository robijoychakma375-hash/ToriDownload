# Changelog

## v0.22.0 — 2026-09-24

- Refreshed desktop download dashboard, queue rows, empty states, and confirmation dialogs.
- Matched extension popup styling and added a hover label to the video button.
- Preserved the Windows installer and portable ZIP build flow from v0.19.

## v0.21.0

- Added available video quality selection and MP3 conversion using bundled FFmpeg.
- Saved quality with each job so retries use the same choice.

## v0.20.0

- Added an on-video button that offers supported public video URLs to Tori.

## v0.19.0

- Added a Windows installer build and a portable ZIP with separate local data.

## Earlier versions

- Developed direct HTTP(S) downloads, queue persistence, browser handoff, resume, and sign-in startup.

See the project history in `README.md` for detailed behavior and limitations.
